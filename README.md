# Product Studio Demo

A bilingual Persian/English interactive demo for a product photography mini app.

Includes sample product scenes, before/after comparison, image downloads, a browser-local gallery, local photo upload previews, and simulated credit purchases.

This is a frontend demonstration. AI sample outputs are pre-generated. Live image processing, Telegram authentication, real payments, and a backend database are not connected. No money is transferred.

Open `index.html` in a browser, or serve this directory as a static website.
